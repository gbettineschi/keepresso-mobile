Personal preview, 100% vibe-coded and provided as is.

- Show Internet and Wi-Fi/network status without treating stale readings as current.
- Improve relay recovery after sleep and saved-connection recovery after unlock or app activation.
- Publish Android and Mac together, with automatic Homebrew updates.

**Android:** install the APK below, or add this repository in Obtainium and enable **Include prereleases**. It uses the same retained signing identity as the owner's 0.4.2 installation; updates preserve data and pairing. No uninstall is needed.

**Mac:** `brew upgrade --cask gbettineschi/tap/keepresso-mobile`, or download `KeepressoMobile.zip`. Apple silicon, macOS 14+. Ad-hoc signed, not notarized; macOS may ask you to approve the saved connection again. Keep one helper in Applications and preserve its Keychain/pairing data.

Verified with Swift, Android core, relay and emulator UI tests, signed Android packaging and the Mac self-check. Physical-device acceptance remains incomplete; see [the checklist](https://github.com/gbettineschi/keepresso-mobile/blob/main/docs/ACCEPTANCE.md).
