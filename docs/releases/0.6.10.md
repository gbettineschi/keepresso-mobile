## Keepresso Mobile 0.6.10 preview

- Status and controls work across networks through iroh. Bluetooth still works nearby.
- Background phone notifications now use Firebase Cloud Messaging from the Mac. Each installation supplies its own Firebase project. This preview requires no Vercel deployment or Firestore database.
- The dashboard uses macOS thermal pressure, checks triggers once after opening, and keeps status stable while reconnecting.
- The new critical alarm, one-time unattended reminder, closed-lid warning and sleep-transition confirmation are available with the experimental native status support described below.

**Install both companion updates from this release.** The signed Android APK updates the previous public preview in place. For existing pairs, reopen the Mac helper and reconnect nearby once so the phone can learn the updated Internet address. Follow the [Firebase setup guide](https://github.com/gbettineschi/keepresso-mobile/blob/main/docs/SELF_HOSTING.md) if you want background alerts.

**Compatibility.** The Mac helper is ad-hoc signed and requires Apple silicon and macOS 14.5+. The phone app requires Android 9+. Stock Keepresso 1.30.0 works for ordinary status and trigger assessment. The new thermal alarm, unattended and closed-lid notifications, and **Sleep now** require additional native wake/session evidence. The official Keepresso download does not currently provide that contract. This release includes the two companion apps.

**Verification.** The alert, recovery and sleep-result flows passed simulated tests. The paired Android app was verified to reconnect and load live Mac status. Locked-phone alarm presentation, real background delivery of the new alerts and physical sleep still need live verification.
