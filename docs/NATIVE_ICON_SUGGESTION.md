# Draft native Keepresso suggestion — not posted

Title: Distinct menu-bar indicator when closed-lid wake mode is active

Could the menu-bar cup show a small lid/closed-laptop marker when system sleep is disabled by closed-lid mode? The brewing icon alone does not distinguish normal brewing from a Mac that will remain awake with its lid closed. A tooltip identifying whether the override is manual or follows “Only while brewing” would make this easier to check before putting the Mac in a bag.

This is a suggestion for the upstream app; Keepresso Mobile does not patch its icons or settings.
